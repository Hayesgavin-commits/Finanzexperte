# Finanzexperte 1.3.0 – GitHub Pages

Alle Dateien in das Stammverzeichnis des GitHub-Repositorys kopieren. Unter GitHub `Settings → Pages` die Quelle `Deploy from a branch`, Branch `main` und Ordner `/(root)` auswählen.

Die Daten werden ausschließlich im lokalen Browser gespeichert. Unterstützt werden einmalige, monatliche, wöchentliche, vierteljährliche und jährliche Buchungen. Der Monatsendstand wird in den Folgemonat übernommen. Ausgaben können zusätzlich einem Sparziel im Bereich „Ansparen“ zugeordnet werden.
