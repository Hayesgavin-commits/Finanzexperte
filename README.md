# Finanzexperte 1.6.0 – GitHub Pages

Alle Dateien in das Stammverzeichnis des GitHub-Repositorys kopieren. Unter GitHub `Settings → Pages` die Quelle `Deploy from a branch`, Branch `main` und Ordner `/(root)` auswählen.

Die Daten werden ausschließlich im lokalen Browser gespeichert. Unterstützt werden einmalige, monatliche, wöchentliche, vierteljährliche und jährliche Buchungen. Jeder Monat besitzt einen eigenen Kontostand; ein Monatsendstand wird nicht in den Folgemonat übertragen. Ausgaben können zusätzlich einem Sparziel im Bereich „Ansparen“ zugeordnet werden.

Wiederkehrende Buchungen können über „Beenden“ oder beim Bearbeiten über „Nicht mehr buchen ab“ taggenau beendet werden.

Die Gesamtübersicht zeigt 13 Monate nebeneinander und die Einnahmen sowie Ausgaben zeilenweise. Jeder Monatskopf öffnet die Detailansicht. Betragsfelder und Buchungszeilen lassen sich direkt zur Bearbeitung auswählen.

In der Einzelmonatsansicht wird für jede Fälligkeit ausschließlich das tatsächliche Buchungsdatum dieses Monats angezeigt. Über „Buchen“ kann ein gespeicherter Posten oder ein neuer Posten ausgewählt werden. Gebuchte Einnahmen erhöhen, gebuchte Ausgaben verringern den eigenständigen Kontostand des gewählten Monats. Jede Fälligkeit kann nur einmal gebucht werden und erhält den Status „Gebucht“.

Neue Buchungen werden über „Neuer Umsatz“ und die anschließende Wahl zwischen Einnahme und Ausgabe erfasst. Die Auswahl und das Formular können jeweils über „Abbrechen“ geschlossen werden. Wiederkehrende Umsätze können monatlich, vierteljährlich oder wöchentlich mit Wochentag angelegt werden. Ausgaben lassen sich als normale Ausgabe oder als Ansparung verbuchen.
