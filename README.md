# Finanzexperte 1.1.0 – GitHub Pages

Alle Dateien in das Stammverzeichnis des GitHub-Repositorys kopieren. Unter GitHub `Settings → Pages` die Quelle `Deploy from a branch`, Branch `main` und Ordner `/(root)` auswählen.

Die Daten werden ausschließlich im lokalen Browser gespeichert. Wiederkehrende Buchungen werden ab ihrem Startmonat bis zum optionalen Endmonat automatisch in jeder Monatsübersicht berücksichtigt.
